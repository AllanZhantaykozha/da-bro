# DA BRO — прототип интернет-магазина

Прототип сайта бутиков мужской одежды и обуви DA BRO (Астана, Уральск). Заказ оформляется на сайте и уходит менеджеру в WhatsApp готовым сообщением.

## Страницы

- `index.html` — главная: о бренде, категории, новинки, как заказать, бутики выбранного города
- `catalog.html` — каталог: поиск, категории, скидки, сортировка
- `product.html?id=N` — товар: галерея (свайп), цвет, размер, «В корзину», «Купить сразу через WhatsApp»
- `cart.html` — корзина: количество, удаление, итог
- `checkout.html` — оформление: контакты, самовывоз из бутика или доставка, оплата → WhatsApp

При первом заходе сайт просит выбрать город (Астана / Уральск). Город влияет на бутики, наличие и то, какому менеджеру уходит заказ.

## Настройка

Всё в `js/data.js`:

- `CONFIG.whatsapp` — номера WhatsApp менеджеров по городам, только цифры с кодом страны, например `"77011234567"`. Пока номер пустой, WhatsApp открывается с готовым сообщением и предлагает выбрать чат.
- `CITIES` — адреса и часы работы бутиков.
- `PRODUCTS` — товары, цены, размеры, фото.

Чистый HTML / CSS / JS, без сборки. Фото товаров — временные (Unsplash), адреса и телефоны — заглушки.
