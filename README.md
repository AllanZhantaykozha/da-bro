# DA BRO — прототип сайта

Прототип сайта бутиков мужской одежды и обуви DA BRO (Астана, Уральск).

- `index.html` — страница «О нас»: история бренда, бутик, принципы, категории, адреса бутиков
- `catalog.html` — каталог: фильтры по категориям, сортировка, быстрый просмотр, выбор размера, избранное, корзина

Чистый HTML / CSS / JS, без сборки. Фото товаров — временные (Unsplash), адреса и цифры — заглушки.
